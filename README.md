# 清华园 · 2.5D

用校园地图(彩色图例的那张)做的简易 2.5D 校园模型:教学科研楼和学生宿舍拉高成体块,体育场、绿地、水面是平的,绿地上撒了秋天颜色的树,地名是小标签。家属住宅区没有画。

运行:`python3 -m http.server 4411` 然后打开 http://127.0.0.1:4411/ 。拖动旋转,双指缩放/平移;右上角可以开关地名、自动旋转、复位。

怎么做出来的:`extract.py` 读地图图片,按图例颜色把每一类区域分出来、描成轮廓,存进 `campus.json`;`app.js` 用 three.js 把轮廓拉成立体。想改建筑高度、颜色、树的数量,改 `app.js`;想加地名,往 `NAMES` 里加 `[名字, 图片里的横坐标, 纵坐标]`。
